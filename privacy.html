Bruno: Privacy Policy

Last updated: 13 October 2026

Bruno is a personal assistant application built by Rakshith Reddy for his own use. It has a single user, its developer, and is not offered to the public.

What data Bruno accesses

With the user's permission, Bruno reads and manages events on the user's own Google Calendar in order to show the user's schedule and to create, change, or delete events and reminders that the user explicitly confirms.

How the data is used

Calendar data is used only to answer the user's own requests. It is not sold, shared with third parties for advertising, or used for any purpose other than providing Bruno's features to its user. Requests are processed by the AI model provider Anthropic to understand and respond to the user.

Storage

Bruno keeps only short-term conversation context for a few minutes to handle follow-up questions. Calendar data stays in the user's Google Calendar.

Revoking access

Access can be removed at any time from the Google Account permissions page: https://myaccount.google.com/permissions

Google API Services

Bruno's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
